DISCORD / OCI

Discord事前予約登録

Original Create Information（OCI）をあなた自身のDiscordアカウントへ個人インストールすると、Original Createの事前予約登録が完了します。

OCI

Original Create Information

OCIを個人インストールして登録

01

下のボタンからDiscordを開きます。

02

OCIをあなたのアカウントに追加します。

03

個人インストール完了と同時に事前予約登録され、OCIからウェルカム案内と使い方を送信します。

Discordで事前予約登録する

Discord登録リンクを準備しています。

運営・管理用DiscordサーバーへのOCI設置は事前予約とは別です。事前予約として扱うのは、利用者本人のDiscordアカウントへの個人インストールのみです。ウェルカムDMを受信できない場合は、個人インストール後にDiscordで /oci を実行してください。

OCI MENU

登録後、そのまま使えます

進行状況Original Createの現在地を確認
配信テスト公開前の配信テストへ移動
視聴テスト公開前の視聴テストへ移動
アルゴリズムテスト各種テストへ直接アクセス
クラウドファンディング企画情報をOCIから確認
事前予約解除OCIの個人インストールを認証解除して事前予約も解除

事前予約を解除する場合は、Discordの「ユーザー設定」→「認証済みアプリ」→「Original Create Information」→「認証解除」を行います。

OCIの個人インストールが認証解除されると、Discordから解除イベントを受信し、Original Create側の事前予約登録も自動で削除されます。

再度事前予約する場合は、OCIをあなたのDiscordアカウントへもう一度個人インストールしてください。
